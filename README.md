## OC-2009-2026
Analysis of CTD profiles to examine seasonal hydrographic structure, surface warming trends, and winter-to-spring transitions in the southeastern Mediterranean, as part of the 2026 Oceanographic Cruise course.
## Scripts
- `clean_liner.r` – Seasonal upper-layer (0–10 m) hydrographic analysis, including median filtering, potential density, \(N^2\), linear regressions, and segmented regressions.
- `clean_warming.r` – Long-term warming analysis for surface (0–10 m) and deep (200–400 m) waters using filtered CTD temperature profiles.
- `ts_diagram.R` – T–S diagram generation with sigma-t isopycnals, including cruise-level and station-level visualizations.
